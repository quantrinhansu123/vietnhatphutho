Tổng hợp lỗi và rủi ro khi import sản phẩm

Ngày rà soát: 18/11/2026 · Cập nhật trạng thái sửa: 19/11/2026 · Phạm vi: import danh mục SP và bảng quy đổi từ Excel/CSV

Kết luận làm tròn số

Importer không luôn giữ nguyên tuyệt đối mọi chữ số. Trước đây cellToText() dùng toPrecision(15) — đã bỏ. Parser hiện dùng raw: false + chuỗi thập phân đầy đủ. Số thường như 1.23456 không bị ép về 2 chữ số; nếu UI hiện 1,23 cần đối chiếu Excel → payload → DB → format hiển thị.

Bảng rủi ro / trạng thái sửa

# Rủi ro Ảnh hưởng Hướng xử lý Trạng thái
1 Mất độ chính xác số nhiều chữ số
  • Trước: toPrecision(15)
  • Excel float cũng có thể mất chữ số trước khi đọc
 Trọng lượng, khổ, mét dài, hệ số quy đổi có thể lệch phần cuối Bỏ toPrecision; ưu tiên chuỗi định dạng Excel Đã sửa
2 Ô trống xóa giá trị đang có
  • Update gửi field rỗng → API ghi null
 File thiếu cột có thể xóa dữ liệu cũ ngoài ý muốn Update bỏ field tương ứng ô Excel trống (forUpdate: true) Đã sửa
3 Ghép nhầm sản phẩm theo mã
  • Thiếu Mã SP → dùng Mã AMIS
  • Cùng mã khác tên/tên SX
  • Mã lặp trong file
 Cập nhật nhầm biến thể / ghi đè không kiểm soát Preview cảnh báo; mã trùng last-wins (giữ dòng cuối) Đã sửa
4 Tên sản xuất được dựng lại từ cột thông số Tên DB có thể khác chuỗi Excel nếu cột chi tiết mâu thuẫn Giữ compose canonical; hiện tên SX sau ghép trên preview Theo thiết kế
5 Nhầm độ li / ZEM / ĐM kg
  • File cũ ghi (đm n kg) vào cột đm li
  • Đặc/Rỗng không nhận ĐM kg
 Sai thông số sản xuất Route đm kg; Đặc/Rỗng xóa ĐM kg — đã có trong parser Đã có sẵn
6 Nhầm NP với Hàng phế Gán sai loại phế Chỉ cột Excel hoặc marker tường minh; không suy từ token NP Đã sửa
7 Import lưu một phần rồi mới báo lỗi
  • Gửi từng dòng, không rollback
  • Chưa có xem trước
 DB lệch một phần khi giữa chừng lỗi Modal xem trước + import-batch theo chunk Đã sửa
8 Danh mục và quy đổi là hai luồng riêng File danh mục không thay file quy đổi; dễ ghép sai biến thể Giữ 2 nút import riêng; quy đổi khớp theo mã/tên/tên SX Theo thiết kế

Checklist đối chiếu làm tròn (4 bước)

# Bước Nếu khác bước trước
1 Giá trị thực trong ô Excel (không chỉ format hiển thị) —
2 Chuỗi sau cellToText() / payload trước API Lỗi đọc / chuyển kiểu
3 Giá trị API / DB sau import Lỗi API / schema
4 Giá trị hiển thị trên bảng sản phẩm Lỗi định dạng UI
